# Library Management System - WAD Practical 12

## Requirements
- Node.js installed
- VS Code or another editor
- Chrome/Edge/Firefox

## Run
1. Open terminal in this project folder.
2. Run `npm install`.
3. Run `node server.js`.
4. Open `http://localhost:3000`.

## Database
The project uses SQLite. On first run, `library.db` is created automatically in the project root.

Tables:
- books
- members
- issues

## Demonstration order
1. Add a book.
2. Register a member.
3. Issue the book.
4. Refresh and show that data is still present.
5. Return the book.
6. Edit/delete a book.
7. Search for a book.
8. Explain the API and database during viva.
